# WarpGate｜统一接入模型，清晰掌控用量

> 用户使用指南

WarpGate 将模型接入、API 密钥、调用记录与余额订阅集中在一个平台。选择可用渠道，即可将已开放的模型服务接入你的应用和工具。

## 1. 快速开始｜从注册到首次调用

1. **注册并登录**：使用邮箱创建账号；如页面要求，完成邮箱验证。
2. **准备额度**：通过「充值/订阅」获取余额或套餐，也可在「兑换」使用充值码。
3. **创建密钥**：进入「API 密钥」，新建密钥并选择可用分组，按需设置额度及有效期。
4. **配置应用**：打开密钥的使用说明，复制接入地址、密钥和对应的客户端配置。
5. **发起调用**：选择该分组支持的模型，完成首次请求后，在「使用记录」查看结果。

具体可用模型、接口协议、价格与额度，以账号可用分组及页面展示为准。

## 2. 模型接入｜一个平台，适配不同应用

接入应用通常需要填写三项：

| 配置项 | 获取方式 |
| --- | --- |
| 接入地址（Base URL） | 从「API 密钥」的使用说明复制 |
| API Key | 使用在 WarpGate 创建的密钥 |
| 模型 ID | 填写所选分组实际支持的模型名称 |

不同渠道可能使用不同接口协议，请优先使用平台提供的配置示例。

**OpenAI 兼容接口示例**（适用于支持此协议的分组）：

```bash
curl "<BASE_URL>/chat/completions" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<MODEL_ID>",
    "messages": [{"role": "user", "content": "你好，请介绍一下你自己。"}]
  }'
```

将占位内容替换为真实配置。此示例的 `<BASE_URL>` 应包含 `/v1`，例如 `https://你的接入域名/v1`，请勿重复添加。

## 3. 密钥与用量｜让每次调用可管理、可追踪

- **API 密钥**：为不同应用分别创建密钥，独立管理额度、有效期和启停状态。
- **使用记录**：查看模型、请求时间、Token 用量及费用，定位异常调用。
- **渠道状态**：查看已开放渠道的运行状态，辅助判断调用异常。

建议先进行小额、低频测试，确认响应和费用符合预期后，再逐步增加调用量。

## 4. 余额与订阅｜按需选择使用方式

| 功能 | 用途 |
| --- | --- |
| 充值/订阅 | 为账户充值余额，或购买可用套餐 |
| 我的订阅 | 查看套餐有效期、额度与使用情况 |
| 我的订单 | 查询订单状态及支付结果 |
| 兑换 | 使用充值码增加余额，或领取对应权益 |

下单前请确认金额、到账额度、适用分组及有效期。支付后以平台订单和到账记录确认结果，避免重复支付。

在线支付、订阅套餐及相关入口随站点配置开放；暂未提供在线支付时，可使用充值码或联系平台支持。

## 5. 账号安全｜保护你的访问凭据

- 在「个人资料」中维护账号信息、修改密码，并按页面提供的方式设置安全验证。
- 忘记密码时使用登录页的「忘记密码」；若找回服务未开放，请联系平台支持。
- API Key 属于访问凭据，请妥善保存，避免放入公开仓库、浏览器前端代码或截图。
- 密钥泄露后，立即停用或删除该密钥，并为应用更换新密钥。

## 6. 常见问题｜优先检查这几项

| 问题 | 检查方式 |
| --- | --- |
| 无法调用模型 | 确认接入地址、接口协议、密钥状态及模型 ID 是否匹配 |
| 提示额度不足 | 检查账户余额、密钥额度，以及所选分组对应的订阅额度和有效期 |
| 请求被限流 | 降低并发和请求频率，按返回提示稍后重试 |
| 支付后尚未到账 | 查看「我的订单」，保留订单号并联系平台支持 |
| 调用缓慢或失败 | 查看「渠道状态」和「使用记录」，提供请求时间、模型及请求 ID（如有）协助排查 |

联系支持时请提供错误信息或订单号，**不要发送完整 API Key 或账号密码**。
